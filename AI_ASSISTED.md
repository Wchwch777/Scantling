# AI-assisted development disclosure

This repository uses AI tools to assist with code, tests, examples, and
documentation. AI-generated or AI-edited work is not represented as
human-authored. The repository owner is responsible for deciding what to merge,
maintain, and release, and should review generated changes before treating them
as owner-approved.

## Current project scope

The maintained project is a MoonBit MQTT 3.1.1 asynchronous TCP client. The
earlier one-dimensional cutting-stock direction is no longer the maintained
scope. Actual capabilities and limitations are documented in the
[project application](docs/project-application.md) and
[README](README.md).
