# AI-assisted development

AI tools assisted with code, tests, README, and project application drafts in this repository. The repository owner selected the project direction and remains responsible for reviewing, maintaining, and releasing the final changes. AI assistance is disclosed here rather than represented as human-authored work.

The current project is a MoonBit MQTT 3.1.1 asynchronous TCP client. The earlier one-dimensional cutting-stock direction is no longer part of the maintained scope. Feature claims and verification status must match the current source, tests, and GitHub Actions results.
